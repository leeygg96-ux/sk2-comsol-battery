# 저장소 아키텍처

## 저장소 경계

### 1. `sk2-comsol-battery` — 현재 저장소

하나의 상위 Git 이력 아래에서 다음 두 모델 계열을 관리한다.

- `thermal-abuse/`: 외부 가열, 열폭주 반응, 셀 간 열전파
- `charge-discharge/`: 충·방전, 전기화학, 정상 운전 발열
- `shared/`: 두 모듈이 실제로 공유하는 좌표계, 형상 규약, 공통 파라미터 스키마 등

의존 방향은 `thermal-abuse -> shared`, `charge-discharge -> shared`만 허용한다. 두 모듈이 서로의 소스 파일을 직접 참조하지 않는다.

### 2. `sk2-paper` — 별도 저장소

논문은 브랜치가 아니라 **완전히 별도 저장소**로 관리한다. 논문 저장소는 COMSOL 저장소의 특정 태그, 커밋 해시, 결과 manifest를 인용한다. 이렇게 하면 원고 수정 이력과 모델 개발 이력이 섞이지 않는다.

## 공유 코드 추출 원칙

처음부터 공통 프레임워크를 크게 만들지 않는다. 양쪽 모듈에서 동일한 구조가 반복되고 인터페이스가 안정된 뒤 `shared/`로 추출한다. 열적 남용 모델만 사용하는 Arrhenius 반응식이나 임계온도 로직은 공유 대상으로 보지 않는다.

## 결과 전달 경계

논문으로 전달하는 결과 묶음에는 최소한 다음을 포함한다.

- COMSOL 저장소 태그 또는 커밋 해시
- 실행 파라미터
- COMSOL 버전
- 생성 일시
- 결과 CSV/그림의 체크섬
- 실행 로그 위치

구체 형식은 `docs/MODEL_HANDOFF.md`에 정의한다.
